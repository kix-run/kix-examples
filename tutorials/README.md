# tutorials/

The numbered example clusters paired with the
[Kix docs tutorial sequence](https://kixops.dev/docs/tutorials/). Each
folder maps to a tutorial of the same number — the docs walk through
the cluster, the cluster file demonstrates the lesson.

Start with [`02-hello-world/`](./02-hello-world/) and walk forward.
The early tutorials are read-along; tutorials `04` and `05` ask you to
build a small cluster yourself rather than reading one from this
directory.

Each `cluster.nix` is meant to be read alongside its docs page. If you
just want to run them locally, see the repo-root
[`README.md`](../README.md).
